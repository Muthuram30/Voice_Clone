Speaker-Adaptive Speech Synthesis Enroll a voice profile, run DSP analysis, and generate natural speech with XTTS-v2.

How it works

  1. Select or create a voice profile (User 1, User 2, or your own)
  2. Record or upload ~2 minutes of the predefined enrollment script
  3. Process & Enroll Voice — DSP analysis, speaker embedding, TTS reference
  4. Enter any text you want to synthesize
  5. Generate speech in that profile's voice, then play or download

The 2-minute recording is a reference sample. No TTS network is trained: a pretrained model (XTTS-v2) is conditioned on the reference; a pretrained ECAPA encoder (or an MFCC baseline) provides the speaker embedding.
